This deliberately simplified 2-D scattering model tests an inverse-problem architecture, not full electromagnetic optics: guess exterior → run known physics forward → compare interior residual → estimate a local response operator → update the exterior. If the inside measurements fit while geometry stays wrong or the Jacobian loses rank, the page says so.
